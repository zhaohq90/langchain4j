# LangChain4j 简介

**LangChain4j** 是一个用于构建 LLM 驱动应用的 Java 库。它的目标不是简单地把某一家模型供应商的 API 包装成 Java SDK，而是为 Java 应用提供一套统一、可扩展、工程化的大模型开发抽象。

借助 LangChain4j，你可以以一致的编程方式接入不同聊天模型、嵌入模型、向量存储与外围组件，并在此基础上构建聊天系统、检索增强生成系统、自动化工作流与更复杂的 Agent 系统。

## 核心能力

LangChain4j 覆盖了从基础 LLM 调用到复杂智能体编排的一整套能力。

| 能力类别 | 说明 |
|---|---|
| 聊天与语言模型 | 接入多家模型供应商，完成对话、生成、分类、重写等任务 |
| Embedding 与向量存储 | 用于语义检索、相似度匹配与 RAG |
| AI Services | 通过接口驱动的方式声明 AI 能力，减少模板代码 |
| Tools | 让模型能够调用外部函数与业务工具 |
| Chat Memory | 支持多轮对话上下文管理 |
| RAG | 支持文档导入、切分、嵌入、存储与检索增强生成 |
| Skills 与 Agent | 用于构建更复杂的任务型智能系统 |
| 流式输出与结构化输出 | 便于面向生产环境构建可消费的输出结果 |

## 两层抽象

LangChain4j 的设计可以分成两层。

第一层是**低层抽象**。在这一层，你会直接使用 `ChatModel`、`UserMessage`、`AiMessage`、`EmbeddingStore`、`Embedding` 等基础类型。这种方式的优点是控制力最强，开发者可以根据自己的业务流程自由组合每一个组件。

第二层是**高层抽象**。在这一层，最常见的是 `AI Services`。它把提示词装配、消息映射、返回结果解析以及部分复杂行为封装起来，让开发者通过接口和注解就可以快速声明一个 AI 能力。

| 层次 | 优势 | 适合人群 |
|---|---|---|
| 低层抽象 | 灵活度高，可精细控制模型调用与流程编排 | 需要深度定制链路的开发者 |
| 高层抽象 | 上手快，代码简洁，适合业务开发 | 想快速构建 AI 功能的开发者 |

## 项目模块结构

LangChain4j 采用模块化设计。`langchain4j-core` 定义基础抽象；`langchain4j` 提供高层能力与常用工具；各类 `langchain4j-{integration}` 模块负责模型供应商、向量存储以及外部系统集成。除此之外，项目还提供文档加载器、解析器、执行引擎、观测能力、Guardrails、MCP 与 Agentic 相关模块。

这种模块化结构的好处是，你可以只引入自己真正需要的依赖，而不必一次性加载完整生态。

## 典型应用方向

从实践角度看，LangChain4j 特别适合以下几类需求。第一类是构建可控的企业聊天助手，例如客服、内部知识问答机器人与教育助手。第二类是对大量非结构化数据执行分析、抽取与总结。第三类是构建具备检索增强能力的知识系统。第四类则是通过 Tools、Skills、Agent 与 MCP 连接外部系统，形成更具执行能力的 AI 应用。
