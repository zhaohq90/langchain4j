# RAG (检索增强生成)

**RAG (Retrieval-Augmented Generation)** 是一种强大的技术，它将大型语言模型（LLM）的生成能力与从外部知识源检索相关信息的能力相结合。其核心思想是，当 LLM 需要回答一个问题或生成一段文本时，它首先会从一个或多个知识库中检索相关信息，然后利用这些检索到的信息来指导其生成过程。

## 为什么需要 RAG

LLM 固然强大，但它们也存在一些固有的局限性：

*   **知识时效性**：LLM 的知识截止于其训练数据，无法获取最新的信息。
*   **幻觉（Hallucinations）**：LLM 有时会生成听起来合理但实际上不准确或捏造的信息。
*   **缺乏领域特定知识**：LLM 可能不具备企业内部文档、特定行业报告等私有或专业领域的知识。
*   **可解释性差**：LLM 的回答通常难以追溯其信息来源。

RAG 通过引入外部知识检索，有效缓解了这些问题：

| RAG 优势 | 说明 |
|---|---|
| **提高准确性** | 基于真实、最新的信息生成回答，减少幻觉 |
| **增强知识** | 能够访问 LLM 训练数据中没有的私有或实时信息 |
| **提供可解释性** | 可以展示回答所依据的原始文档片段 |
| **降低成本** | 对于某些任务，RAG 可以减少对更大、更昂贵模型的依赖 |

## RAG 的工作原理

RAG 通常涉及两个主要阶段：**索引（Indexing）** 和 **检索（Retrieval）**。

### 索引阶段 (Indexing)

索引阶段的目标是准备你的知识库，使其能够被高效地检索。这通常包括：

1.  **文档加载 (Document Loading)**：从各种来源（如文件系统、数据库、网页等）加载原始文档。
2.  **文档解析 (Document Parsing)**：将加载的文档解析成可处理的文本格式，可能包括去除格式、提取关键信息等。
3.  **文档分割 (Document Splitting)**：将长文档分割成更小、更易于处理的块（chunks），因为 LLM 的上下文窗口有限。
4.  **嵌入 (Embedding)**：使用嵌入模型将每个文本块转换为高维向量（即嵌入），这些向量捕获了文本的语义信息。
5.  **存储 (Storing)**：将这些嵌入及其对应的文本块存储到**嵌入存储（Embedding Store）** 中，也称为向量数据库。

索引阶段通常是离线进行的，这意味着它不需要最终用户等待其完成。例如，可以通过一个每周在周末重新索引公司内部文档的 cron 作业来实现。负责索引的代码也可以是一个单独的应用程序，只处理索引任务。然而，在某些场景下，最终用户可能希望上传他们的自定义文档，使其可供 LLM 访问。在这种情况下，索引应该在线执行，并成为主应用程序的一部分。

### 检索阶段 (Retrieval)

检索阶段通常是在线进行的，当用户提交一个需要使用索引文档回答的问题时。这个过程可能因所使用的信息检索方法而异。

对于向量搜索，这通常涉及：

1.  **查询嵌入 (Query Embedding)**：将用户的查询（问题）也转换为一个嵌入向量。
2.  **相似性搜索 (Similarity Search)**：在嵌入存储中执行相似性搜索，找到与用户查询向量最相似的文档块。
3.  **注入提示词 (Prompt Injection)**：将检索到的相关文档片段注入到 LLM 的提示词中，然后发送给 LLM。

## LangChain4j 中的 RAG 风格

LangChain4j 提供了三种 RAG 风格：

*   [简易 RAG (Easy RAG)](/tutorials/easy-rag-zh)：最简单的 RAG 入门方式。
*   **朴素 RAG (Naive RAG)**：使用向量搜索实现 RAG 的基本实现。
*   **高级 RAG (Advanced RAG)**：一个模块化的 RAG 框架，允许额外的步骤，如查询转换、从多个来源检索和重新排序。

## 学习建议

*   **理解 RAG 全链路**：不要只关注某个组件，要从文档加载到最终生成回答的整个流程来理解 RAG。
*   **从简易 RAG 开始**：如果你是 RAG 新手，可以先从 [简易 RAG](/tutorials/easy-rag-zh) 开始，快速建立对 RAG 工作原理的直观感受。
*   **深入核心 API**：当你需要更多控制和定制时，再深入学习 LangChain4j 的核心 RAG API，包括 `DocumentLoader`、`DocumentParser`、`TextSplitter`、`EmbeddingModel` 和 `EmbeddingStore`。
*   **实践不同向量存储**：尝试集成不同的向量数据库，了解它们的特点和适用场景。

掌握 RAG 将使你的 LLM 应用能够处理更复杂、更专业的知识密集型任务，是构建企业级 AI 应用的关键能力之一。
