# LangChain4j

**LangChain4j** 是一个面向 Java 的开源框架，用于构建基于大语言模型（LLM）的应用。它提供统一的抽象与丰富的集成能力，帮助开发者以更工程化的方式接入聊天模型、嵌入模型、向量存储、工具调用、RAG、Agent 与多种周边能力。

如果你正在使用 Java 生态，希望快速构建聊天助手、知识库问答、数据抽取、内容生成、自动化工作流或更复杂的 Agent 系统，LangChain4j 提供了从底层模型调用到高层声明式 API 的完整能力。

## 为什么使用 LangChain4j

LangChain4j 的核心价值在于，它把原本分散的大模型接入、提示词构造、消息管理、工具调用、知识检索、记忆管理与多模型集成整合为一致的 Java 编程体验。开发者既可以使用低层 API 精细控制每一步，也可以直接使用高层 API 快速构建具备生产可用性的 AI 功能。

| 能力方向 | 主要内容 |
|---|---|
| 模型接入 | 支持多种 LLM 提供商与多种嵌入模型 |
| 高层开发 | 提供 AI Services 等高级 API，减少样板代码 |
| RAG | 支持文档导入、切分、向量化、存储、检索与增强生成 |
| Agent 能力 | 支持 Tools、Agent、Skills、MCP 以及更复杂的 Agentic 模式 |
| 工程化支持 | 支持聊天记忆、流式响应、结构化输出、观测、测试等 |

## 主要能力概览

LangChain4j 提供的能力覆盖从基础聊天到复杂智能体系统的多个层次。围绕一个典型的 LLM 应用，你可以先接入聊天模型实现对话，然后逐步扩展为具备记忆、工具调用、知识检索与多代理协作能力的系统。

它当前提供的主要能力包括：与多种聊天模型和嵌入模型的集成、与多种向量数据库的集成、AI Services 高层 API、Tools、RAG、Chat Memory、流式响应、结构化输出、Skills、Agent 与 Agentic AI 能力，以及多种文档加载器和解析器等。

## 两层抽象

LangChain4j 采用两层抽象设计。

第一层是**低层抽象**。在这一层中，你会直接接触 `ChatModel`、`UserMessage`、`AiMessage`、`EmbeddingStore`、`Embedding` 等核心原语。它提供最大的灵活性，适合需要完全自定义控制流程的场景。

第二层是**高层抽象**。在这一层中，你可以通过 `AI Services` 等高级 API 以声明式方式与模型交互。它隐藏了大量底层复杂性与样板代码，适合更快地搭建业务能力，同时也保留了必要的可配置性。

| 抽象层级 | 特点 | 适用场景 |
|---|---|---|
| 低层抽象 | 控制力强，组合自由度高 | 需要自定义消息流、检索流、工具流程或底层模型行为时 |
| 高层抽象 | 开发效率高，代码更简洁 | 快速构建聊天、问答、提取、分类、工具型助手等应用时 |

## 项目结构概览

从仓库结构看，LangChain4j 由多个模块组成。

`langchain4j-core` 提供最核心的抽象定义；`langchain4j` 模块提供面向应用开发最常用的高层能力；大量 `langchain4j-{integration}` 模块则分别负责与各类模型提供商、向量存储、框架与外围系统集成。此外，项目还包含文档加载器、文档解析器、执行引擎、MCP、Skills、Guardrails、观测与测试等模块。

## 典型使用场景

LangChain4j 适用于多类 AI 应用开发场景。它不仅能帮助你构建一个简单的聊天机器人，也能支持更复杂的数据处理、知识增强与自动化流程系统。

| 场景 | 说明 |
|---|---|
| 聊天助手 | 构建企业客服、教育助手、内部 Copilot 等对话系统 |
| 知识问答 | 接入企业文档、FAQ、知识库，实现 RAG 问答 |
| 信息抽取 | 从简历、评论、网页、报告中提取结构化信息 |
| 内容生成 | 生成邮件、摘要、报告、故事、营销文案等 |
| 自动化执行 | 通过工具调用、Agent 与外部系统协作完成任务 |
